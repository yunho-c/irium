# AGENTS.md

## Commit Convention

Please use descriptive commit messages, with the following details:

- Use `feat`, `fix`, `chore`, or `misc` prefix (e.g., "feat(settings): add dark mode toggle")
- Describe the changes using bullet points

## Code Quality

- Please focus on writing clean, maintainable code.
- Avoid using hacks/band-aid solutions that will be problematic later.
